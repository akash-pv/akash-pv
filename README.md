## 🚀 Projects

### 🔹 Azure Data Lakehouse Pipeline
- Built scalable **Lakehouse architecture on Microsoft Azure** using AdventureWorks dataset (~77,000 rows)
- Implemented **Medallion Architecture — Bronze, Silver, Gold layers** using Databricks & PySpark
- Built **2 ADF pipelines** — static and dynamic parameterised (Lookup + ForEach) ingesting 10 CSV files from GitHub via HTTP linked service
- Applied PySpark transformations — `concat_ws`, `split`, `regexp_replace`, `to_timestamp`, `month`, `year`
- Created **8 Gold layer views** via Synapse Serverless SQL using `OPENROWSET` over Silver Parquet files
- Built external tables with Managed Identity auth and Snappy-compressed Parquet
- 🔗 [View Project](https://github.com/akash-pv/azure-data-lakehouse-pipeline)

### 🔹 AI Newsletter Management System
- Built full-stack **Newsletter Management System** with role-based workflows
- Multi-stage approval pipeline — Admin, Approver, User — backed by MySQL
- Integrated **Ollama Mistral 7B** for AI article generation — reduced drafting time by **67%** (~45 min → ~15 min) in internal testing
- Built **Analytics Module** tracking open rates, click-through rates, AI vs manual performance
- Automated weekly CSV export via node-cron — runs every Monday 8AM
- Tested with **25 internal users** — avg open rate **72%**, avg click rate **38%**
- 🔗 [View Project](https://github.com/akash-pv/newsletter-system)

### 🔹 Pneumonia Detection using VGG19
- Built a **Deep Learning model using VGG19** for pneumonia detection from chest X-rays
- Applied **Transfer Learning** with TensorFlow/Keras — achieved **90% test accuracy** (Model 3)
- 3-phase training strategy — frozen base → partial unfreezing → full fine-tuning
- Trained on **5,856 chest X-ray images** with data augmentation
- **Published at SACAIM 2024** — International Conference on Advance IT, Engineering & Management
- 🔗 [View Project](https://github.com/akash-pv/Automated-pneumonia-detection-using-vgg19)
